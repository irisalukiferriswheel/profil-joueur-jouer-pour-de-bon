# Local signup/profile preview

Branch `codex/signup-profile-completion`, base profile PR #2 `c12445ebc7c6da1ce97a8cde8b72e0163b7ea773`. Companion Wix base is PR #34 `34300ea8cda57631ac32d95d4aaff4019a01deea`. No publication or live signup replacement.

The existing `app.js` editor now includes canonical game choices from its existing backend catalog, handles string/object saved game values, prevents duplicate submits, keeps entered values on save errors, and rejects stale acknowledgements. Background data replies cannot overwrite an active draft. Existing dashboard and event behavior are covered by regression tests. City remains the existing free-text field pending a canonical server catalog. Existing social fields are retained; their upstream persistence was already unsupported by the onboarding method and is not redesigned here.

`signup-preview.html` is a local mock review artifact, not a new deployed Wix page/account model. Open through a local HTTP server with `?lang=fr` or `?lang=en`. It simulates Wix login and uses the shared field validator/flow controller in `profile-fields.js`. Alias, fixture city string, games, directory visibility and private `invitationEmails` are supported in memory. Both consent switches default off. No credentials, accounts, messages or durable writes are involved; refreshing resets the fixture. `profile-fields.test.mjs` covers authentication failure/cancellation, pending verification, expired session, interrupted/existing account resume, duplicate submit and retry. Durable interrupted-profile resumption remains an API prerequisite.

See companion `wix-signup/SIGNUP-REVIEW.md` for the required-field conflict, atomic persistence/canonical city/private consent blockers and staged activation sequence. The compact flow is deliberately not connected to production. The original profile UI remains French; the compact preview has FR/EN variants. Full localization of the original dashboard is outside this diff.

Validation: 71 automated tests pass across both repos; existing organizer regression passes. Browser screenshots: task-4/signup-fr-1200.png, signup-en-390.png and existing-editor-mobile.png. Browser assertions cover compact completion/re-edit, consent defaults, no mobile overflow, no console errors, and original editor game save/re-edit. Keyboard and assistive-technology acceptance still require staging review.
